# Page 43 — Troubleshooting (Vulcan OmniPro 220 Multiprocess Welder, Item 57812)

## Troubleshooting Table

| Problem | Possible Causes | Likely Solutions |
|---|---|---|
| Welder Does Not Function When Switched On | 1. Tripped thermal protection device. | 1. If a warning screen appears in the LCD Display window, Welder may have overheated and shut down. Stop and wait with the Power Switch ON for the Welder to cool. The Welder automatically returns to service after cooling off. Reduce duration or frequency of welding periods to help reduce wear on the Welder. Refer to *Duty Cycle (Duration of Use)* on page 19. |
| Welder Does Not Function When Switched On | 2. Circuit supplies insufficient input voltage or amperage. | 2. Verify that the circuit is designed to supply the required input voltage and amperage as detailed on the Specifications table. If a warning screen appears in the LCD Display window, check the input voltage to ensure it is within specified range. |
| Welder Does Not Function When Switched On | 3. Faulty or improperly connected Trigger. | 3. Ensure the gun connection is properly seated on machine. Qualified technician must check and secure/replace Trigger. |
| Welder Does Not Function When Switched On | 4. Machine is in low- or over-voltage protection. | 4. Check input voltage and ensure it falls within the specified range. If input voltage is correct, press Reset Button on back of machine. |
| Welder Does Not Function When Switched On | 5. Machine is in the incorrect mode. | 5. Ensure the correct process has been selected. |
| LCD Display Does Not Light When Welder is Switched On | 1. Unit is not connected to outlet properly. | 1. Verify the voltage at the outlet and the connection to the outlet. |
| LCD Display Does Not Light When Welder is Switched On | 2. Outlet is unpowered. | 2. Check circuit breaker/GFCI devices; if any are tripped, determine and remedy cause before resetting. |
| LCD Display Does Not Light When Welder is Switched On | 3. Plug does not have correct rating. | 3. Make sure installed plug is correct rating. See *Specifications* on page 7. |
| LCD Display Does Not Light When Welder is Switched On | 4. Circuit breaker has tripped due to high input amperage. | 4. Press Reset Button on back of machine to reset circuit breaker. |
| LCD Display Does Not Light When Welder is Switched On | 5. Input Power Cord is not seated properly. | 5. Ensure the twist lock input Power Cord is fully secured. |
| Wire Feeds, but Arc Does Not Ignite | 1. Improper ground connection. | 1. Make certain that the workpiece is contacted properly by the Ground Clamp and that the workpiece is properly cleaned near the ground clamp and the welding location. |
| Wire Feeds, but Arc Does Not Ignite | 2. Improperly sized Contact Tip. | 2. Verify that Contact Tip is the proper size for welding wire. If needed, replace Contact Tip with proper size and type. |
| Wire Feeds, but Arc Does Not Ignite | 3. Excessively worn Contact Tip. | 3. Check that the hole in the tip is not deformed or enlarged. If needed, replace Contact Tip with proper size and type. |
| Wire Feeds, but Arc Does Not Ignite | 4. Dirty Contact Tip. | 4. Properly clean Contact Tip. |
| Porosity in the Weld Metal | 1. Shielding gas bottle is empty. | 1. Check gas bottle and replenish as necessary. |
| Porosity in the Weld Metal | 2. Not enough or too much shielding gas. | 2. Check gas regulator to ensure proper flow. |
| Porosity in the Weld Metal | 3. Dirty workpiece. | 3. Clean workpiece down to bare metal. |
| Porosity in the Weld Metal | 4. Gun is being used too far away from workpiece. | 4. Check CTWD (contact tip to work distance) for the proper procedure. |
| Porosity in the Weld Metal | 5. Polarity is incorrect for the application. | 5. Check the polarity and ensure it is DCEP for MIG and DCEN for Flux-Cored. |
| Porosity in the Weld Metal | 6. Dirty welding wire is introducing contamination into the weld. | 6. Make certain that welding wire is clean and free of rust and residues. |

**Note (below table):** Follow all safety precautions whenever diagnosing or servicing the equipment.
